# Online resources and provenance

This project uses and acknowledges the following public resources. Adapted
function bodies are marked at the function with a `// provenance:` comment and
are recorded in the submission card used by the integration gate.

## Reference decompilations

- [doldecomp/dolsdk2001](https://github.com/doldecomp/dolsdk2001) — Dolphin SDK
  matching decompilation; preferred SDK reference.
- [doldecomp/melee](https://github.com/doldecomp/melee) — Super Smash Bros.
  Melee reference tree.
- [doldecomp/sms](https://github.com/doldecomp/sms) — Super Mario Sunshine
  reference tree.
- [doldecomp/mkdd](https://github.com/doldecomp/mkdd) — Mario Kart: Double Dash!!
  reference tree.

## Build and analysis tools

- [decomp-toolkit](https://github.com/encounter/decomp-toolkit) — GameCube/Wii
  project tooling and DOL splitting.
- [objdiff](https://github.com/encounter/objdiff) — object and progress diffing.
- [wibo](https://github.com/decompals/wibo) — Win32 wrapper used to run MWCC on
  Linux.
- [sjiswrap](https://github.com/encounter/sjiswrap) — Shift-JIS compiler-input
  wrapper.
- [decomp.me](https://decomp.me) — community scratch-and-diff service. Scratch
  payloads are prepared locally before any public submission.
- [decomp.dev](https://decomp.dev) — progress-report ecosystem and schema
  reference.
